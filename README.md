# Зал

Особистий iOS-додаток для тренувань у залі з фокусом на набір м'язової маси.
Офлайн, без акаунтів, реклами й аналітики. Усі дані зберігаються тільки на телефоні.

> Інформація в додатку не є медичною порадою. Якщо під час вправи з'явився біль, зупинись. При хронічних захворюваннях порадься з лікарем.

**Що вміє:** анкета при першому запуску → норма калорій і БЖВ, прогноз; 5 програм (основна «Маса 3 дні: Спліт»); 71 вправа з фото, технікою, помилками та альтернативами; режим тренування з підказками ваги за подвійною прогресією, таймером відпочинку (також на заблокованому екрані), рекордами і калькулятором дисків; прогрес (графіки сили, ваги, об'єму по м'язах, заміри, фото до/після); харчування (меню під твою норму, щоденник, вода, поради); цілі, досягнення, нагадування, база знань; резервна копія в файл.

---

## 1. Що потрібно

- Mac з **Xcode 26.x** (перевірено з 26.3)
- iPhone з **iOS 26**
- Кабель USB-C / Lightning
- Apple ID (підходить безкоштовний)

## 2. Перше встановлення

1. Отримай код: Xcode → **Integrate → Clone…** → `https://github.com/nokk1993/Zalizo.git` (або `git clone` у Терміналі). Відкрий `Zalizo.xcodeproj`.
2. **Xcode → Settings → Accounts** → «+» → Apple ID → увійди.
3. Ліворуч клацни синю іконку **Zalizo** → для кожного таргета (**Zalizo**, **ZalizoWidgets**, **ZalizoTests**) відкрий вкладку **Signing & Capabilities** і вибери **Team** = «Твоє ім'я (Personal Team)».
   - Bundle ID уже унікальний (`ua.zalizo.app.b82a66`, віджет: `….widgets`). **Не змінюй його**, інакше телефон вважатиме це іншим додатком і дані «зникнуть».
4. Підключи iPhone кабелем, на телефоні натисни **«Довіряти цьому комп'ютеру»**.
5. На iPhone увімкни **Режим розробника**: Параметри → Приватність і безпека → Режим розробника → увімкнути → перезавантаження → підтвердити. Цей пункт з'являється тільки після того, як телефон хоч раз підключили до Xcode.
6. У Xcode вгорі вибери свій iPhone як пристрій для запуску → **Run (⌘R)**.
7. Перший запуск заблокується з повідомленням «Ненадійний розробник». Тоді: Параметри → Загальні → **VPN і керування пристроєм** → твій Apple ID → **Довіряти**. Після цього знову Run.
8. (Опційно) Xcode → Window → **Devices and Simulators** → свій iPhone → **Connect via network**. Далі можна ставити по Wi-Fi без кабелю.

## 3. Кожні 7 днів (безкоштовний акаунт) і оновлення

З безкоштовним Apple ID підпис діє **7 днів**, після чого додаток перестає відкриватися.
Щоб продовжити (або поставити нову версію), підключи телефон і знову натисни **Run**. **Дані збережуться.**

Оновити код: Xcode → **Integrate → Pull** (або `git pull`), потім Run.

⚠️ **Не видаляй додаток з телефону** перед перевстановленням: видалення стирає всі дані. Перед будь-якими експериментами зроби резервну копію.

## 4. Резервна копія і відновлення

- **Профіль → Резервна копія → Створити резервну копію.** Перемикач «Включити фото» додає фото прогресу у файл (він стане більшим).
- Натисни **«Зберегти у «Файли» / надіслати»**: можна зберегти в iCloud Drive, «Файли» або надіслати собі в Telegram.
- **Відновити з файлу** → обери `Zal-backup-YYYY-MM-DD.json` → «Замінити все» або «Об'єднати з поточними» (додаються лише записи, яких ще немає).
- **Історія тренувань у CSV** для Excel/Numbers.
- Додаток нагадує про копію раз на 2 тижні (вимикається в Налаштуваннях).

## 5. Типові помилки і що робити

| Повідомлення | Що робити |
|---|---|
| **Untrusted Developer / Ненадійний розробник** | Параметри → Загальні → VPN і керування пристроєм → Довіряти (крок 7). |
| **Could not launch "Zalizo"** | Телефон заблокований: розблокуй і натисни Run ще раз. Якщо не допомогло, спершу перевір довіру до розробника. |
| **Provisioning profile expired / додаток не відкривається через тиждень** | Минули 7 днів: підключи телефон і натисни Run (розділ 3). |
| **Developer Mode disabled** | Увімкни Режим розробника (крок 5) і перезавантаж телефон. |
| **The maximum number of apps for free development profiles has been reached** | Безкоштовний акаунт дозволяє **3 власні додатки** одночасно. Видали з телефону інший тестовий додаток (не «Зал»!). |
| **Failed to register bundle identifier / App ID limit** | Безкоштовний акаунт може створювати до **10 App ID за 7 днів**. Зачекай або не змінюй Bundle ID. |
| **Помилка підпису саме для ZalizoWidgets** | Віджет потрібен тільки для таймера на заблокованому екрані. Тимчасовий обхід: таргет **Zalizo** → Build Phases → **Embed Foundation Extensions** → прибери `ZalizoWidgets.appex` (кнопка «−»). Додаток працюватиме, таймер лишиться у звичайних сповіщеннях. |
| **Сповіщення таймера не приходять** | Параметри → Сповіщення → Зал → дозволити. |

## 6. Як змінити дані і програму

- **Мої дані:** Профіль → Змінити мої дані. Перед збереженням додаток покаже, що зміниться (калорії, БЖВ, прогноз, програма), і попросить підтвердження.
- **Пройти анкету заново:** Профіль → Пройти анкету заново (історія лишається).
- **Програма:** вкладка «Програма» → кнопка ⇄ вгорі, щоб обрати іншу або створити свою. Дні можна переставляти (Редагувати), вправи замінювати, міняти підходи, повтори, відпочинок і RIR. «Скопіювати програму» робить твою копію вбудованої.
- **Обладнання і травми** (Профіль → Мої дані) автоматично замінюють вправи безпечнішими або доступними альтернативами. Це видно в програмі з позначкою ⇄.
- **Налаштування:** кроки ваги, гриф і диски, таймер, звук і вібрація, формула 1ПМ, тема, нагадування.

## 7. Опційні функції

- **Live Activity:** таймер відпочинку і наступний підхід на заблокованому екрані та в Dynamic Island. Працює через таргет ZalizoWidgets і вимикається в Налаштуваннях.
- **Apple Health:** вимкнено за замовчуванням, щоб додаток гарантовано підписувався безкоштовним акаунтом. Щоб увімкнути: таргет **Zalizo** → Signing & Capabilities → **+ Capability → HealthKit** → Run, потім у додатку Налаштування → «Синхронізація з Apple Health». Якщо Xcode видасть помилку підпису, значить твій тип акаунта HealthKit не підтримує: прибери capability назад.
- **Віджети домашнього екрана** не зроблено: щоб передати дані у віджет, потрібна App Group, а з безкоштовним Personal Team вона, найімовірніше, недоступна.

## 8. Для розробки

```sh
sh Tools/check.sh          # збірка під симулятор + усі тести (додаток і ZalizoCore)
cd Packages/ZalizoCore && swift test   # лише тести логіки (працює й на Linux)
```

Генератори вбудованих даних (запускати з кореня репозиторію):

```sh
python3 Tools/seed/exercises_seed.py      # вправи → Zalizo/Resources/Seed/exercises.json
python3 Tools/seed/import_exercise_images.py /шлях/до/free-exercise-db   # фото вправ
python3 Tools/seed/programs_seed.py       # програми + таблиця тижневого об'єму
python3 Tools/seed/nutrition_seed.py      # продукти і меню
python3 Tools/seed/knowledge_seed.py      # статті бази знань
python3 Tools/make_icon.py                # іконка
```

Після зміни вправ збільш `SEED_VERSION` у генераторі: тоді додаток оновить вбудовані вправи, не чіпаючи твоїх правок.

## 9. Структура

- `Zalizo/` - додаток (SwiftUI + SwiftData): `App/`, `Models/` (схема v1 + план міграцій), `Services/`, `Features/…`, `DesignSystem/`, `Resources/` (seed JSON, Asset Catalog, String Catalog)
- `Packages/ZalizoCore/` - уся бізнес-логіка без UI (розрахунки, прогресія, парсер, меню, статистика, бекап) і її тести. Це локальний модуль цього репозиторію, а не стороння залежність.
- `WidgetExtension/` - Live Activity
- `ZalizoTests/` - тести бази даних і сервісів
- `Tools/` - генератори даних і скрипти
- `ASSETS_LICENSE.md` - ліцензії фото (Free Exercise DB, Unlicense)
