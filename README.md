# Залізо

Особистий iOS-додаток для тренувань у залі з фокусом на набір м'язової маси.
Офлайн, без акаунтів і реклами. Усі дані зберігаються тільки на телефоні.

> Інформація в додатку не є медичною порадою. Якщо під час вправи з'явився біль, зупинись. При хронічних захворюваннях порадься з лікарем.

## Що потрібно

- Mac з **Xcode 26.x** (перевірено з 26.3)
- iPhone з **iOS 26**
- Кабель USB-C / Lightning
- Apple ID (підходить безкоштовний)

## Перше встановлення

1. Відкрий `Zalizo.xcodeproj` у Xcode.
2. **Xcode → Settings → Accounts** → «+» → додай свій Apple ID.
3. Ліворуч вибери проєкт **Zalizo** → таргет **Zalizo** → вкладка **Signing & Capabilities**:
   - **Team** = «Твоє ім'я (Personal Team)»;
   - **Bundle Identifier** уже унікальний (`ua.zalizo.app.b82a66`). Не змінюй його, бо інакше телефон вважатиме це іншим додатком і дані «зникнуть».
   - Те саме **Team** вибери для таргета **ZalizoTests**.
4. Підключи iPhone кабелем і на телефоні натисни «Довіряти цьому комп'ютеру».
5. На iPhone увімкни **Режим розробника**: Параметри → Приватність і безпека → Режим розробника → увімкнути → перезавантаження → підтвердити.
6. У Xcode вгорі вибери свій iPhone як пристрій для запуску → **Run (⌘R)**.
7. Перший запуск на телефоні: Параметри → Загальні → VPN і керування пристроєм → твій Apple ID → **Довіряти**. Потім знову Run.
8. (Опційно) Xcode → Window → Devices and Simulators → свій iPhone → **Connect via network**. Далі можна ставити по Wi-Fi без кабелю.

## Кожні 7 днів (безкоштовний акаунт)

З безкоштовним Apple ID підпис діє 7 днів, після чого додаток перестає відкриватися.
Щоб продовжити, підключи телефон і знову натисни **Run** у Xcode. **Дані збережуться.**
**Не видаляй додаток з телефону** перед перевстановленням: видалення стирає всі дані (якщо немає резервної копії).

## Перевірка збірки і тестів

```sh
sh Tools/check.sh
```

Тести чистої логіки (пакет `Packages/ZalizoCore`) можна запустити й окремо: `cd Packages/ZalizoCore && swift test`.

## Структура

- `Zalizo/` — додаток (SwiftUI + SwiftData): `App/`, `Models/`, `Services/`, `Features/…`, `DesignSystem/`, `Resources/`
- `Packages/ZalizoCore/` — бізнес-логіка без UI (розрахунки, прогресія, парсер, бекап) з юніт-тестами. Це локальний модуль цього ж репозиторію, а не стороння залежність.
- `ZalizoTests/` — тести бази даних і інтеграції
- `Tools/` — допоміжні скрипти (генерація іконки, перевірка)

*Повна інструкція (бекап, типові помилки) з'явиться в README на фінальному етапі.*
